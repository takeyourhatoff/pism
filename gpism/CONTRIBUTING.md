# Contributing to gpism

Thanks for helping build gpism. Please keep changes small and reviewable.

## Workflow

- Base work on the `gpism-main` branch.
- Create feature branches named `gpism-main-feat-<short-topic>`.
- Keep `PLAN.md` updated as work progresses.

## Coding and formatting

- Follow existing repo formatting tools (see `.clang-format`).
- Prefer small, focused commits with descriptive messages.

## Testing

- Run relevant tests for your change.
- Note any skipped tests in your PR description.
